# ربات هوشمند فروش VPN (مبتنی بر کلودفلر)

این یک سورس پیشرفته و بهینه برای راه‌اندازی ربات فروش سرویس‌های VPN بر بستر **Cloudflare Workers** است. این ربات با استفاده از فریم‌ورک **Grammy** و پایگاه داده **Cloudflare D1** ساخته شده و از چندین پنل VPN و درگاه پرداخت پشتیبانی می‌کند.

## 🚀 قابلیت‌های کلیدی

### بخش کاربر:
- **خرید آنی**: انتخاب محصول، پرداخت از کیف پول و دریافت آنی کانفیگ.
- **مدیریت سرویس**: مشاهده حجم باقی‌مانده، تاریخ انقضا و دریافت مجدد لینک اتصال به صورت خودکار.
- **کیف پول**: شارژ حساب از طریق درگاه‌های آنلاین یا کارت‌به‌کارت (با ارسال رسید).
- **اکانت تست**: قابلیت دریافت اکانت تست رایگان برای کاربران جدید.
- **احراز هویت**: تایید شماره موبایل و عضویت اجباری در کانال اطلاع‌رسانی.
- **سیستم تیکت**: ارتباط مستقیم با تیم پشتیبانی از داخل ربات.

### بخش مدیریت:
- **مدیریت محصولات**: تعریف پلن‌های مختلف با حجم و زمان دلخواه.
- **مدیریت پنل‌ها**: اتصال همزمان به چندین پنل (Marzban, 3x-ui, Hiddify).
- **گزارش‌گیری**: مشاهده آمار فروش، درآمد کل و تعداد کاربران.
- **مدیریت متن‌ها**: تغییر پیام‌های ربات و بخش سوالات متداول بدون تغییر در کد.

### پنل‌های پشتیبانی شده:
- Marzban
- 3x-ui
- Hiddify
- (و قابلیت افزودن سایر پنل‌ها به دلیل ساختار ماژولار)

## 🛠 پیش‌نیازها

1. یک حساب کاربری در [Cloudflare](https://dash.cloudflare.com/).
2. توکن ربات تلگرام (دریافت از @BotFather).
3. نصب بودن Node.js و npm روی سیستم شما.

---

## 📥 آموزش نصب و راه‌اندازی

### ۱. نصب وابستگی‌ها
ابتدا پروژه را دانلود کرده و در پوشه اصلی دستور زیر را اجرا کنید:
```bash
npm install
```

### ۲. ساخت پایگاه داده D1
یک دیتابیس D1 در پنل کلودفلر خود بسازید:
```bash
npx wrangler d1 create vpn_bot_db
```
پس از ساخت، `database_id` ارائه شده را در فایل `wrangler.toml` جایگزین کنید.

### ۳. اعمال جدول‌ها (Migrations)
برای ساخت جداول مورد نیاز در دیتابیس:
```bash
npx wrangler d1 execute vpn_bot_db --file=./schema.sql
```
*(توجه: ابتدا باید خروجی SQL از drizzle تهیه کنید یا از فایل طرح اولیه استفاده کنید)*

### ۴. تنظیم توکن ربات
توکن ربات خود را به عنوان یک Secret در کلودفلر ست کنید:
```bash
npx wrangler secret put BOT_TOKEN
```

### ۵. تنظیمات فایل wrangler.toml
مطمئن شوید مقادیر `name` و `database_id` در فایل `wrangler.toml` به درستی وارد شده‌اند.

### ۶. انتشار (Deploy)
در نهایت پروژه را روی کلودفلر منتشر کنید:
```bash
npm run deploy
```

### ۷. ست کردن وبهوک (Webhook)
پس از انتشار، آدرس URL دریافتی از کلودفلر را به تلگرام معرفی کنید:
`https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=<YOUR_WORKER_URL>/webhook`

## 🔑 تعیین ادمین
برای دسترسی به پنل مدیریت، باید شناسه تلگرام خود را در جدول `admins` دیتابیس وارد کنید. می‌توانید از بخش D1 در پنل کلودفلر دستور زیر را اجرا کنید:
```sql
INSERT INTO admins (telegram_id, level) VALUES (YOUR_ID, 'superadmin');
```
